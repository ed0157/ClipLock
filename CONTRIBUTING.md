# Contributing

Thanks for your interest in ClipLock. It is a small project, so keep changes small and focused.

- Open an issue first for anything bigger than a bug fix.
- To build: `scripts/build.sh` (see the README).
- **Never paste real clipboard contents, passwords or keys** into an issue, pull request or screenshot. Use made-up examples such as `alex@example.com`.
- Security problems: see [SECURITY.md](SECURITY.md) and do not open a public issue.
- Contributions are accepted under the MIT licence of this project.
